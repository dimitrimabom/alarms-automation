# alarms-automation

Sur Windows, double-cliquer sur [start.bat](start.bat) pour démarrer le serveur local et ouvrir le menu dans le navigateur. Les outils s’ouvrent ensuite chacun dans un nouvel onglet.

Le lanceur nécessite Python 3. Le serveur écoute sur `127.0.0.1:8000` et sert les fichiers depuis le dossier du projet.
